# Agente S1-R3: Comissão Julgadora

## Propósito
Selecionar bolsistas por mérito, aplicando os critérios definidos no TR/Edital.
Atua como banca temporária para cada processo seletivo.

## Composição
- Mínimo 3 membros (Art. 9º, §1º)
- Maioria servidores do IPEA (Art. 9º, §1º)
- Presidente: Gestor-Pesquisador solicitante ou Coordenador de Área
- GLM atua como membro consultivo (analisa currículos vs critérios)

## Ferramentas
- GLM 5.2 para análise curricular comparativa
- Planilha de pontuação automática
- Workflow de homologação

## Autonomia
- **Faz sozinho**: avaliar currículos, aplicar critérios, gerar parecer técnico,
  classificar candidatos, homologar resultado
- **Precisa coordenar**: se nenhum candidato atende os critérios (S2 Comitê Gestor),
  se há empate técnico (voto do presidente)
- **Precisa aprovação**: resultado final (Diretor DIEST ou DIDES)

## Critérios de Avaliação (sugeridos pelo GLM)
1. Titulação (peso conforme TR)
2. Experiência em pesquisa no tema
3. Publicações relevantes
4. Adequação do perfil ao projeto
5. Entrevista (se prevista no TR)
6. Prova prática (se prevista no TR)
